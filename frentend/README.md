# storeseco-web

الموقع الرسمي (Next.js) للمخازن الاقتصادية — واجهة عرض/تسويقية تستهلك نفس API الخاص بلوحة تحكم اللارفل (`ecostore-panel`) اللي يستخدمها تطبيق الجوال، بدون أي اعتماد على ووكومرس.

## التشغيل محلياً

1. تأكد إن لوحة تحكم اللارفل (`ecostore-panel`) شغّالة محلياً (افتراضياً على `http://localhost:8001`):
   ```
   cd ../ecostore-panel
   php artisan serve --port=8001
   ```
2. انسخ `.env.local.example` إلى `.env.local` وعبّي القيم (مفتاح API مخصص لهذا الموقع — شوف قسم "مفتاح API" تحت).
3. ثبّت الحزم وشغّل السيرفر:
   ```
   npm install
   npm run dev
   ```

## مفتاح API

الموقع يقرأ كتالوج المنتجات/الفئات عبر `/api/v2/*` بنفس آلية تطبيق الجوال (Basic Auth بمفتاح مخصص، خاص بلوحة `ApiKey`). أُنشئ مفتاح مستقل خاص بالموقع (بلابل `storeseco-web (Next.js website)`) بدل إعادة استخدام مفتاح التطبيق — لفصل الصلاحيات وسهولة الإلغاء لاحقاً لو احتجنا. لتوليد مفتاح جديد:

```
cd ../ecostore-panel
php artisan tinker --execute="\$k = App\Models\ApiKey::create(['label' => 'اسم وصفي']); echo \$k->key . ' / ' . \$k->plainSecret;"
```

## مصادر البيانات (كل شي من اللارفل، بدون ووكومرس)

| القسم بالواجهة الرئيسية | المصدر | قابل للتعديل من لوحة التحكم؟ |
|---|---|---|
| البنر الرئيسي (Hero) | `/api/app-config` → `webCarouselBanners` | ✅ لوحة البنرات — نوع "بنر خاص بالموقع" |
| الكاردات الصغيرة (أعلى/أسفل) | `/api/app-config` → `promoCards` / `promoBottomCards` | ✅ لوحة البنرات — نفس الكاردات المشتركة مع التطبيق |
| شبكة الأقسام | `/api/v2/categories` | ✅ لوحة الفئات |
| صف المميزات (٤ شعارات) | `/api/app-config` → `storeSettings.badges` | ✅ إعدادات المتجر → "شعارات الثقة" |
| شريط الإعلان | `/api/app-config` → `storeSettings.announcement_*` | ✅ إعدادات المتجر → "شريط الإعلان" |
| بيانات التواصل بالفوتر | `/api/app-config` → `storeSettings` | ✅ إعدادات المتجر → "معلومات التواصل" |
| قسم تحميل التطبيق + بنر "أسعار أوفر" | ثابت بالكود حالياً | ❌ لسا مو مربوط بلوحة التحكم |

إذا الباك اند غير متاح وقت البناء/التشغيل، كل استدعاء يفشل بهدوء لقيمة افتراضية فاضية بدل ما يكسر الصفحة (شوف `src/lib/api.ts`).

## قبل الرفع على استضافة جديدة (AWS أو غيرها)

- عدّل `BACKEND_URL` بـ`.env` ليشير لدومين لوحة التحكم الفعلي (مو `localhost`).
- أضف دومين الإنتاج (ولو لسا موجود `storeseco.com` القديم بأي صور) إلى `images.remotePatterns` في `next.config.ts`.
- الموقع يحتاج Node.js runtime (مو استضافة PHP-only) — يشتغل بأي من: خادم Node عادي (`npm run build && npm run start`)، أو AWS Amplify Hosting، أو حاوية Docker على ECS/EC2.
- أضف مفتاح API إنتاجي منفصل (مو نفس مفتاح التطوير).

## الصفحات الناقصة (خارج نطاق الواجهة الرئيسية الحالية)

الروابط بالهيدر/الفوتر (`/browse`, `/about`, `/contact`, `/faq`, `/policies/*`) موجودة كروابط لكن صفحاتها لسا ما بُنيت — الواجهة الرئيسية فقط هي المكتملة بهذه المرحلة.
